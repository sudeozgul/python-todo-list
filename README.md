# Python To-Do List Application

A command-line task management application developed with Python.
It allows users to add, view, update, and delete tasks while saving
their task list to a text file.

## Features

- Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks
- Prevent empty and duplicate task entries
- Prevent renaming a task to a name that already exists
- Handle empty task lists when deleting or editing tasks
- Save tasks to a text file
- Load saved tasks when the application starts
- Handle invalid user input and file operation errors

## Technologies

- Python
- Lists
- Functions
- File handling (reading and writing text files)
- Input validation
- Exception handling

## How to Run

1. Clone this repository.
2. Open the project folder in a terminal.
3. Run:

   `python to-do_list.py`

On Windows, if the `python` command is not recognized, use:

   `py to-do_list.py`
